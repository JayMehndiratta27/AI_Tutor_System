# AI_Tutor_System

AI Tutor – AI-Powered Smart Learning Platform
AI Tutor is an AI-powered educational web application developed as a final-year major project for the Bachelor of Technology in Computer Science and Engineering. The platform aims to make learning more interactive and personalized by integrating artificial intelligence into the learning process.
The application provides an AI chatbot that answers students' questions, personalized learning recommendations, automated quiz generation from educational content, and automatic evaluation of students' answers. These features are designed to help students understand concepts, practice their knowledge, and receive feedback through a unified learning platform.
The project uses AngularJS for the frontend and Python for the backend, connecting the user interface with backend services to support the platform's learning functionality.
Key Features
- AI Chatbot: Enables students to ask questions and receive AI-generated responses to support their learning.
- Personalized Learning: Recommends relevant learning materials according to students' needs or learning performance.
- Automated Quiz Generation: Generates questions from educational content to help students practise and assess their understanding.
- Automatic Answer Evaluation: Evaluates students' answers and provides feedback to support learning and self-assessment.
- Interactive User Interface: Provides a structured interface for accessing learning resources and interacting with the platform.
- Frontend–Backend Integration: Connects the AngularJS frontend with Python backend services.
